# kitty keymaps

## Window

| Key | Action | Tags |
|---|---|---|
| ctrl+shift+enter | New kitty window | window split |
| ctrl+shift+w | Close kitty window | window close |

## Tab

| Key | Action | Tags |
|---|---|---|
| ctrl+shift+t | New tab | tab create |
| ctrl+shift+q | Close tab/window | tab close |
| ctrl+shift+right | Next tab | tab navigation |
| ctrl+shift+left | Previous tab | tab navigation |

## Scrollback

| Key | Action | Tags |
|---|---|---|
| ctrl+shift+h | Browse scrollback in pager | scrollback history |

## Hints

| Key | Action | Tags |
|---|---|---|
| ctrl+shift+p->f | Highlight file paths and URLs | hints terminal path url |
| ctrl+shift+p->shift+f | Open selected file path | hints terminal path open |
| ctrl+shift+p->w | Highlight words | hints terminal word |
| ctrl+shift+p->l | Highlight lines | hints terminal line |
| ctrl+shift+p->h | Highlight git commit hashes | hints terminal git hash |
| ctrl+shift+p->n | Open file:line in editor | hints terminal file line compiler stacktrace |
| ctrl+shift+p->y | Open terminal hyperlinks | hints terminal hyperlink url |
