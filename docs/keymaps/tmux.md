# tmux keymaps

## Pane

| Key | Action | Tags |
|---|---|---|
| prefix + z | Zoom current pane | pane window zoom |
| prefix + x | Kill current pane | pane kill |
| prefix + % | Split pane horizontally | pane split |
| prefix + " | Split pane vertically | pane split |

## Window

| Key | Action | Tags |
|---|---|---|
| prefix + c | Create new window | window create |
| prefix + , | Rename current window | window rename |
| prefix + n | Next window | window navigation |
| prefix + p | Previous window | window navigation |

## Session

| Key | Action | Tags |
|---|---|---|
| prefix + d | Detach session | session detach |
| prefix + s | Choose session | session switch |
| prefix + b | Previous session | session switch |


## Plugin

| Key | Action | Tags |
|---|---|---|
| prefix + P | Start/Stop Recording Screen | Screen Recording |
| prefix + alt + p | Screen Capture | Screen Capture |
| prefix + alt + P | Save Complete Screen History | Capture Screen |
